SPARSH WEBSITE - HOW TO EDIT
============================
Files:
  index.html  - page text and structure (headings, paragraphs, contact, footer)
  style.css   - colours, fonts, spacing, layout (colours are at the top in :root)
  script.js   - animations, bag colours, cards data, WhatsApp link
  images/     - logo.jpg and bags.jpg (replace with your own images, keep same names)

Open index.html in a browser to see the site. Save a file and refresh to see changes.

Common changes:
  Phone number  -> search 9054837242 / 9978327241 in index.html AND script.js
                   (WhatsApp links use format 91XXXXXXXXXX)
  Email         -> search sparshcarrybags@gmail.com in index.html
  Brand colours -> style.css, :root block at the top
  Hero text     -> index.html, search "Carried"
  Bag colours   -> script.js, const V
  Industries    -> script.js, const I
  Steps         -> script.js, const S

Tip: keep a backup copy before editing. Use VS Code (free) for easy editing.
